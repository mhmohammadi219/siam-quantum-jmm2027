# SIAM Minisymposium — JMM 2027

Website for:

**SIAM Minisymposium on Recent Advances in Quantum Computing Algorithms and Applications**

Friday, January 15, 2027.

## Publish with GitHub Pages

1. Create a new public GitHub repository, for example:
   `siam-quantum-jmm2027`

2. Upload `index.html` to the root of the repository.

3. Open the repository's **Settings**.

4. Select **Pages** in the left sidebar.

5. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**

6. Click **Save**.

GitHub will publish the site at an address similar to:

`https://YOUR-USERNAME.github.io/siam-quantum-jmm2027/`

## Editing

All content and styling are currently contained in `index.html`, so the page is easy to maintain without a build system.
